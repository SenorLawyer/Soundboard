# Reporting a vulnerability

Report a security issue through [GitHub's private vulnerability form](https://github.com/SenorLawyer/Soundboard/security/advisories/new). Include the app version, Windows version and the shortest reproduction you have. If a media file triggers the issue, share it privately and identify the codec.

For routing or playback problems without a security impact, use the [issue tracker](https://github.com/SenorLawyer/Soundboard/issues).
